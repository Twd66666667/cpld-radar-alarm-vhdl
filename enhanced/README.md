# 提高功能版工程

使用Quartus II 9.1打开`radar_enhanced.qpf`。该工程与根目录基础版工程分别编译、分别烧录，共用已经验证过的超声波、距离换算、三次滤波和LCD总线模块。

当前功能：

- 舵机按照5°步进在0°～180°之间往返扫描；
- 每400 ms更新一次目标角度；
- 每一步先驱动舵机80 ms，再关闭PWM并等待50 ms；
- 静默后连续测量三次，使用中值结果更新五个参考方向；
- LCD完成自检、待机雷达图和五方向障碍物显示；
- 运行时在雷达图底部角度轴显示一个随舵机角度每5°移动的十字扫描标记；
- 保留基础版的LED距离分级、蜂鸣器节奏报警、数码管角度与距离显示以及双色点阵五方向显示。数码管角度覆盖全部5°步进值。

提高版使用独立的LCD、数码管和点阵控制模块，因此不会影响根目录的基础版工程。动态标记直接由0～36扫描序号换算为角度轴位置，避免使用占用较大的37项二维坐标表。

完整编译结果为0 errors、0 warnings，逻辑单元占用1239/1270（98%）。生成的烧录文件为`radar_enhanced.pof`，该文件属于本地编译产物，不提交到Git。器件只剩31个逻辑单元，因此不再加入任意角度的二维距离点；上板时应重点检查数码管角度递增和递减、点阵五方向颜色、声光分级以及LCD扫描标记方向。
