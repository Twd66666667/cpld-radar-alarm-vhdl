# 三模式融合试验（暂不可烧录）

这个目录是独立试验工程，不改动已上板验证的 `fusion/`。SW7 控制开关；SW6=0 为基础模式；SW6=1 且 SW5=0 为提高模式；SW6=1 且 SW5=1 为跟踪模式。跟踪只增加 `target_tracker_ctrl`，与另外两种模式共用舵机 PWM、37 档校准脉宽表、超声波、三次测距滤波、数码管和 LCD；LED、点阵和蜂鸣器在原有模式中的行为保留。

已把普通扫描器中的脉宽表和角度数码拆出，三个模式共用一份 `tracking_servo_map`。还试写了结构更紧凑的 LCD 控制器，保留半圆轮廓与障碍点；跟踪模式每次结果后重绘背景，避免旧点长期残留。这个 LCD 版本仅通过综合，尚未完成波形和上板验证。

Quartus II 9.1 对 EPM1270T144C5 的综合通过、无警告；Fitter 报 1386 个逻辑单元，而器件只有 1270 个，超出 116 个。因此本试验没有可用的 POF，也不能烧录。原融合工程未被替换。若要坚持同芯片三模式，需要进一步改变显示或基础模式功能；否则继续分别烧录当前已完成的融合版和跟踪版更稳妥。
