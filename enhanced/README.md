# 提高功能版工程

使用 Quartus II 9.1 打开 `radar_enhanced.qpf`。该工程和根目录的基础版工程分别编译、分别烧录，共用已经验证过的超声波测距、距离换算、三次中值滤波和数码管模块。

提高版把资源集中在慢速连续扫描和 LCD 半圆雷达图上：

- 舵机以 5° 为一步，在 0°～180°之间往返扫描，共有 37 个角度；
- 每 650 ms 更新一次角度，每一步先输出 80 ms 舵机 PWM，再关闭 PWM 并等待 50 ms；
- 静默后连续测量三次，取中值作为该角度的距离；
- LCD 以屏幕底部中央为圆心，显示 200、400、600、800 mm 四级半圆距离线；
- 测量距离按 20 mm 一级转换成半径，在对应的 5°方向写入一个 3×3 实心障碍物点；
- LCD 自带的显示 RAM 用来保留本轮扫描轨迹。扫描回到 0°后清除上一轮轨迹并重画背景，不需要在 CPLD 内保存 37 组高精度距离；
- 数码管保留，左侧三位显示当前角度，右侧四位显示当前毫米距离；
- LED、双色点阵和蜂鸣器在提高版中关闭，输出保持在确定的关闭电平。基础版仍保留完整声光报警功能。

距离超过 800 mm 时画在最外圈，低于 800 mm 时以 20 mm 为一级，因此 LCD 图形可以区分到十位数量级。数码管仍显示测距模块输出的完整毫米值，不受 LCD 量化影响。障碍物点使用实心块，是为了避免目标恰好落在距离圆弧上时看不清。

LCD 控制器采用增量绘图：背景只在模式切换或新一轮扫描开始时重画，每次测量只计算并写入一个点。四条距离线逐像素判断 `x²+y²≈r²`，平方值通过连续奇数累加得到，因此显示的是圆弧而不是多边形近似。方向坐标通过共用加法器逐拍计算，除以 20 也通过重复减法完成，避免在 MAX II 中生成乘法器和除法器。

本版顶层为 `radar_enhanced_top`。为了在 EPM1270 中实现真正的圆弧计算，提高版不再综合蜂鸣器和报警等级逻辑，把资源集中在 LCD 图形功能上。Quartus II 9.1 完整编译通过，Fitter 使用 1238/1270 个逻辑单元（97%）和 74/116 个引脚，1 MHz 时钟的时序要求全部满足。编译中的固定输出警告来自主动关闭的 LED、点阵和蜂鸣器。生成的烧录文件为 `radar_enhanced.pof`，属于本地编译产物，不提交到 Git。

上板时主要检查：半圆距离线是否完整；舵机是否按 5°往返移动；数码管角度是否与舵机方向一致；障碍物是否在对应方向和半径出现；回到 0°后上一轮轨迹是否被清除。
