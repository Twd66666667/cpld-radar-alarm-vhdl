# 提高功能版工程

使用Quartus II 9.1打开`radar_enhanced.qpf`。该工程与根目录基础版工程分别编译、分别烧录，共用已经验证过的超声波、距离换算、三次滤波和LCD总线模块。

当前功能：

- 舵机按照5°步进在0°～180°之间往返扫描；
- 每400 ms更新一次目标角度；
- 每一步先驱动舵机80 ms，再关闭PWM并等待50 ms；
- 静默后连续测量三次，使用中值结果更新五个参考方向；
- LCD完成自检、待机雷达图和五方向障碍物显示。

完整编译结果为0 errors、0 warnings，逻辑单元占用875/1270（69%）。生成的烧录文件为`radar_enhanced.pof`，该文件属于本地编译产物，不提交到Git。

下一步将在本工程内增加随5°扫描角度移动的LCD扫描标记，并根据上板结果调整400 ms扫描周期、80 ms驱动时间和50 ms静默时间。
