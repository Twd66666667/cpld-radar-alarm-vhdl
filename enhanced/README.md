# 提高功能版工程

使用Quartus II 9.1打开`radar_enhanced.qpf`。该工程与根目录基础版工程分别编译、分别烧录，共用已经验证过的超声波、距离换算、三次滤波和LCD总线模块。

当前功能：

- 舵机按照5°步进在0°～180°之间往返扫描；
- 每400 ms更新一次目标角度；
- 每一步先驱动舵机80 ms，再关闭PWM并等待50 ms；
- 静默后连续测量三次，使用中值结果更新五个参考方向；
- LCD完成自检、待机雷达图和五方向障碍物显示；
- 运行时在雷达图外沿显示一个随舵机角度每5°移动的十字扫描标记。扫描标记与实心障碍物点采用不同形状，重合或靠近时仍容易区分。

提高版使用独立的`enhanced_lcd_renderer`，因此动态显示不会影响根目录的基础版工程。角度到屏幕坐标采用37项查表实现，避免在CPLD内使用三角函数或乘法器。

完整编译结果为0 errors、0 warnings，逻辑单元占用1193/1270（94%）。生成的烧录文件为`radar_enhanced.pof`，该文件属于本地编译产物，不提交到Git。由于器件只剩77个逻辑单元，本版不再加入任意角度的距离坐标点；上板后先检查扫描标记的方向、位置和刷新连贯性，再调整400 ms扫描周期、80 ms驱动时间和50 ms静默时间。
