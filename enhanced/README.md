# 提高功能版工程

使用 Quartus II 9.1 打开 `radar_enhanced.qpf`。该工程和根目录的基础版工程分别编译、分别烧录，共用已经验证过的超声波测距、距离换算、三次中值滤波和 LCD 总线模块。

提高版把资源集中在连续扫描和 LCD 雷达显示上：

- 舵机以 5° 为一步，在 0°～180°之间往返扫描，共有 37 个角度；
- 每 400 ms 更新一次目标角度，每一步先输出 80 ms 舵机 PWM，再关闭 PWM 并等待 50 ms；
- 静默后连续测量三次，取中值作为该角度的距离结果；
- LCD 保存 37 个角度的障碍物等级，每个角度占 3 列。屏幕从左到右对应 180°到 0°，五条横线表示五个距离区间，顶部光标显示当前扫描位置；
- 数码管保留，左侧三位显示当前角度，右侧四位显示当前距离；
- 蜂鸣器保留，按照当前距离等级报警；
- LED 和双色点阵在提高版中关闭，输出保持在确定的灭灯电平，不参与显示。

LCD 保存的是五级距离信息，不是完整的毫米数。这样只需记录 37 个 0～5 的等级，能够在 EPM1270 的资源范围内完成全角度扫描记录。系统进入运行状态后，第一轮扫描会逐步填满 37 个位置，完整单程约需 14.8 s；后续扫描会持续刷新已有结果。

本版完整编译通过，顶层为 `radar_enhanced_top`，满足时序要求。Fitter 最终使用 1151/1270 个逻辑单元（91%），使用 74/116 个引脚。编译时会出现 LED 和点阵输出固定为高、低电平的警告，这是提高版主动关闭它们造成的正常结果。生成的烧录文件为 `radar_enhanced.pof`，属于本地编译产物，不提交到 Git。

上板时主要检查四件事：舵机是否按 5° 往返移动；数码管角度是否与舵机方向一致；LCD 的光标和 37 个距离位置是否逐步更新；当前距离变化时蜂鸣器节奏是否正确。
